## Goal
完成台股篩選器純前端頁面，從 FinMind + TWSE OpenAPI 拉資料，支援 7 項滑桿篩選條件與 5 年詳細分析；並在 FastAPI 後端補上真實年報酬（CAGR）資料。

## Constraints & Preferences
- 使用 FinMind API 抓日股價（`TaiwanStockPrice`）、財報（`TaiwanStockFinancialStatements`）、資產負債表（`TaiwanStockBalanceSheet`）、股利（`TaiwanStockDividend`）
- TWSE 使用 `BWIBBU_ALL`（PE/Yield/PB）與 `STOCK_DAY_ALL` CSV 端點
- **`openapi.twse.com.tw` 無 CORS header**，僅 `www.twse.com.tw` CSV 端點有 `Access-Control-Allow-Origin: *`
- Yahoo Finance chart API **無 CORS header**，無法從 browser 直接 fetch → 需透過 FastAPI 後端代理
- FinMind 免費 token 每小時 600 次限額，`TaiwanStockHoldingSharesPer` 需付費等級才能存取
- `python:3.12-slim` 的 `libcurl`/`openssl` 版本與 Yahoo Finance 不相容（`curl: (35) TLS connect error`）
- 篩選條件保留 7 項：收盤價、殖利率、年報酬(1年)、填息天數、EPS、本益比、ROE

## Key Decisions
- 篩選器用 FinMind API（CORS open，免 token）作為主要資料源，TWSE BWIBBU_ALL 補 PE/Yield/PB
- 年報酬與填息天數保留在篩選器 UI 但 screener 中無歷史資料時自動跳過篩選，詳細頁才有完整 5 年計算
- 預設值放寬到多數股票可通過，使用者再自行拉緊
- **年報酬改為 FastAPI 後端 `/api/v1/cagr`**：背景執行緒從 Yahoo Finance 抓 Adj Close 算 1 年 CAGR，取代 screener 原來的當日漲跌%代理值
- **FinMind holdings dataset 改為每輪最多 200 檔**（`MAX_STOCKS_PER_RUN=200`），避免撞 600/hr 限額
- **FinMind 403 視同 rate limit**（原只 log 不處理），觸發 ban + 拋錯中斷迴圈
